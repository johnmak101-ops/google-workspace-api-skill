# Google Workspace API Skill

A local TypeScript skill for Kimi Code, Claude Code, and OpenPave. It calls ordinary Google Workspace APIs directly, without a broker, third-party server, MCP dependency, or Developer Preview enrollment.

## Status

Initial implementation in progress.

## Platforms

Node 24.22.1 on Windows, macOS, and Linux. GitHub Actions runs the build, tests, stale-bundle check, and vulnerability audit on all three platforms.
